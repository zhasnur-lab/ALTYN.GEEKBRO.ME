# ALTYN — сайт ресторана (altyn.geekbro.me)

Ресторан «ALTYN», Усть-Каменогорск, пр. Каныша Сатпаева, 1е. Instagram @meiramhana_altyn.

## Что внутри
- **/** — сайт: меню с ценами (128 позиций, 18 категорий), сеты, залы (общий 60 мест, VIP «Большой» 25, «Малый» 15, VIP-комната 10), бронь столика/мероприятия, галерея (рилсы Instagram + фото гостей 2ГИС), отзывы (2ГИС + свои), контакты, карта; RU/ҚАЗ; заказ самовывоз/доставка.
- **/t/N** — QR-меню стола N: заказ на кухню, «Официант», «Счёт», оплата Kaspi QR, статус заказа, оценка визита (4–5★ → 2ГИС, 1–3★ → лично управляющему).
- **/staff** — панель. Официант (PIN): Зал, Брони, Стоп-лист, QR. Администратор (пароль) редактирует ВСЁ содержимое:
  - «Меню»: фото блюда (сжимается на телефоне, сохраняется сразу), названия/состав RU+ҚАЗ, цена прямо в списке, старая цена (акция), метки, порядок ↑↓, скрыть/стоп-лист, дублировать/удалить; «Категории»: переименовать, порядок, скрыть, удалить с переносом блюд, «что советовать» в корзине.
  - «Главная»: фото и тексты первого экрана, 4 карточки преимуществ, блок сетов, рейтинг 2ГИС.
  - «Залы»: фото, название, тип, места, описание, NEW, скрыть, порядок, добавить/удалить.
  - «Галерея»: видео Instagram по ссылке (обложка подтягивается сама), фото (несколько сразу), подписи, порядок.
  - «Отзывы»: публикация, ответ, ручное добавление. «Настройки»: Kaspi QR, контакты, доставка/самовывоз, столы, обслуживание %.
- Старое описание панели: живая доска заказов (звук + уведомления), вызовы столов, брони (подтверждение в WhatsApp), стоп-лист, редактор меню с фото, отзывы, печать QR столов, настройки (Kaspi QR, доставка, залы). PIN (STAFF_PASS) — официант, пароль (ADMIN_PASS) — администратор. Оба в `.env`.

## Устройство
- `server.mjs` — Node без зависимостей, :4326, systemd **user** unit `altyn.service`. Данные `data/db.json` (бэкапы `data/backups/`), фото из админки `data/uploads/`.
- `public/` — index.html + app.js + styles.css (гость), staff/ (панель), img/gis (фото из отзывов 2ГИС), img/ig (обложки рилсов).
- `tools/seed.mjs` → `seed.json` — стартовые данные (меню из хайлайта «МЕНЮ» Instagram, 2026). db.json создаётся из seed.json, если его нет.
- `tools/menu-2026-10.json` — новое меню (октябрь 2026, исходник от ресторана — `docs/menu-2026-10.docx`): цены, новые блюда, категории «Шашлыки» и «Десерты». `tools/seed.mjs` накладывает его на исходное меню через `tools/menu-merge.mjs`.

## Обновление меню на работающем сайте
Скрипт `tools/apply-menu.mjs` накладывает файл меню на живые данные через API админки, перезапуск не нужен. Фото, метки, стоп-лист и переводы сохраняются. Убранные позиции **скрываются, а не удаляются**: их можно вернуть в «Меню». Сеты, милкшейки и всё, что добавлено в админке, остаются как есть.
```bash
cd ~/services/altyn && git pull
ADMIN_PASS=… node tools/apply-menu.mjs tools/menu-2026-10.json            # пробный прогон — только список изменений
ADMIN_PASS=… node tools/apply-menu.mjs tools/menu-2026-10.json --write    # применить; копия прежнего меню → menu-before-*.json
ADMIN_PASS=… node tools/apply-menu.mjs --restore menu-before-….json       # откат
```
- nginx: `deploy/zz-altyn.geekbro.me.conf` (всё проксируется на :4326), go-live: `sudo bash deploy/deploy-root.sh` (аддитивно, с проверкой регрессии чужих сайтов, certbot).

## Оплата Kaspi
Статический Kaspi QR ресторана загружается в /staff → Настройки. Гость видит QR + сумму счёта, платит в приложении Kaspi и жмёт «Я оплатил» → официант сверяет поступление в Kaspi Pay и закрывает стол. Автоматическое подтверждение оплаты требует договора с Kaspi (Kaspi Pay API) — можно подключить позже.
